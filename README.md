\\# 和云风 AI营销传播助手







\\## 项目简介



基于 DeepSeek 大模型打造的“双引擎”智能营销中台，聚焦短视频创作与直播合规，旨在为“素人创作者”与“中小商家”打破技术壁垒。







\\## 技术栈



\\- \\\*\\\*前端交互\\\*\\\*：Streamlit + 深度定制 CSS（玻璃拟物化 UI）



\\- \\\*\\\*大模型\\\*\\\*：DeepSeek API（`deepseek-chat`）



\\- \\\*\\\*数据处理\\\*\\\*：Pandas（流式解析与动态表格渲染）



\\- \\\*\\\*安全机制\\\*\\\*：HTML Escape XSS 防护、本地规则库正则拦截







\\## 大模型选型与 Prompt 设计



\\- \\\*\\\*选型理由\\\*\\\*：选用 `deepseek-chat` 而非 R1，是因为在“分镜生成”和“合规改写”任务中，V3 版本的生成速度极快，且在 temperature 参数控制下，能够稳定输出严格的 Markdown 和 JSON 格式，符合 SaaS 工具的响应要求。



\\- \\\*\\\*差异化温度设计\\\*\\\*：



\&#x20;   - `TEMP\\\\\\\_SCRIPT = 0.7`：分镜创意生成，需要较高的发散性。



\&#x20;   - `TEMP\\\\\\\_EDIT = 0.5` / `TEMP\\\\\\\_DIAG = 0.6`：教程与诊断，需要适度的发散。



\&#x20;   - `TEMP\\\\\\\_LEGAL = 0.3`：合规审查，需要极度严谨，避免幻觉。







\\## 人机协作边界（Human-in-the-loop）



\\- \\\*\\\*AI 职责\\\*\\\*：快速生成初稿分镜、初步排查违规词、生成安全改写话术。



\\- \\\*\\\*人类职责\\\*\\\*：在可编辑表格中二次修订台词、决定最终发布的版本、导出 CSV 后实地拍摄。



\\- \\\*\\\*安全兜底\\\*\\\*：采用“本地正则引擎 + AI 语义精修”双层审查，确保极限词零漏网。







\\## 已知限制



\\- \\\*\\\*演示级验证码\\\*\\\*：当前验证码通过前端 Toast 弹窗提示，生产环境将接入真实短信服务商。



\\- \\\*\\\*无持久化\\\*\\\*：数据存储在 Streamlit `session\\\\\\\_state` 中，刷新或关闭页面后数据销毁，生产环境将接入 SQLite/Redis。
